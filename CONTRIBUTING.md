# Contributing to Anurag1 projects

Thanks for contributing. Contributions are welcome when they improve reproducibility, correctness, documentation, evaluation, security, or useful functionality.

## Before opening a PR

1. Read the repository README and existing issues.
2. Prefer a focused change over a broad rewrite.
3. State the problem, proposed change, and how it was tested.
4. For research claims, distinguish hypotheses from demonstrated results.
5. Include reproducible commands or a minimal test case when practical.
6. Do not commit secrets, API keys, credentials, private data, or generated large artifacts.

## Research contributions

For AI/research repositories, useful contributions include:

- stronger baselines
- ablations
- mathematical formalization
- benchmark datasets
- reproducibility fixes
- counterexamples and falsification tests
- provenance/evidence improvements
- independent replication

A negative result is valuable when it is reproducible and clearly documented.

## Pull requests

Use a descriptive title. Explain:

- What changed?
- Why?
- How was it tested?
- What remains uncertain?

Please keep unrelated changes in separate PRs.
